Binary Expression Tree Project

Description
This project uses Python to build a binary expression tree from a postfix expression. It uses a stack and recursion to solve math expressions.


Files
stack.py - Stores items in a stack.
binary_expression_tree.py - Builds and evaluates the expression tree.
main.py - Runs the program.
test_binary_expression_tree.py - Tests the program.


How to Run
To run the program, enter: python3 main.py
To run the tests, enter: python3 -m unittest -v

Example
Input: 5 3 8 * +
Infix: (5 + (3 * 8))
Postfix: 5 3 8 * +
Result: 29.0
